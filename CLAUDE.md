\# Git Workflow



After completing a requested coding task, check the Git status.



If there are changes related to the task:



1\. Stage the relevant changes.

2\. Create a commit with a clear message describing the completed change.

3\. Push the commit to the `origin` remote on the `main` branch.

4\. Do not commit `.env`, API keys, passwords, secrets, `node\_modules`, or other ignored files.

5\. If the push fails, report the error instead of repeatedly retrying.

6\. Do not push unrelated changes that were already present before the current task.



The project is connected to:

\- Remote: `origin`

\- Branch: `main`



The goal is to keep the local VS Code project and the GitHub repository synchronized after completed Claude Code tasks.
